tiling-windows

A tiling window manager for the DOM

Think Hyprland, but for the web. The layout engine owns the tiling logic - BSP, columns, and grid - and never touches a real element; a renderer adapts that to any surface. tiling-windows-dom is the reference HTMLElement renderer powering the demo below.

Open the demo View on GitHub

Multiple strategies

Swap between BSP, columns, and grid layout strategies without touching your app code.

Drag to rearrange

Grab a window and drop it against an edge to split the workspace, or right-click to close it.

Renderer-agnostic core

The layout engine never touches a real element - a Renderer contract adapts it to DOM, canvas, React, or anything else.
